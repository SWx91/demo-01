## Parent

Part of #3 (Sales and reporting).

## What to build

Reject a sale confirmation whenever any line has insufficient stock. Confirmation validates the latest stock for every line; if any one is short, the entire document is rejected and the affected products are identified. No line is posted partially.

`Covers:` SAL-02 (whole-document rejection, affected products, no partial posting). AC-05.
`Demo:` staff_b01 selling 11 packs of SKU001 when stock is 10 is rejected, SKU001 is identified as affected, and no sale or stock deduction is created
`Seams:` oRPC controller spec; Postgres integration spec

## Acceptance criteria

- [ ] A confirmation with any insufficient line is rejected in full and returns the affected products (oRPC controller spec; fails today — no stock validation on confirm). [SAL-02]
- [ ] Selling 11 packs of SKU001 when stock is 10 creates no confirmed sale and no stock deduction (Postgres integration spec; fails today). [AC-05]
- [ ] No line is posted when any other line is insufficient (Postgres integration spec; fails today). [SAL-02]
