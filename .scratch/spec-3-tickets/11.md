## What to build

Provide a movement-history report filtered by product, store, movement type, and date range, with access to the source document behind each movement. A store employee sees their assigned store only; a manager sees all stores. Export as Thai-safe CSV with the same filters and permissions.

`Covers:` RPT-03 (movement history); RPT-04 (movement CSV); US-12; US-13
`Demo:` movement history for B01 filtered by type shows each movement with a link to its source document; staff_b01 sees only B01; a manager sees all stores; CSV exports Thai-safe
`Seams:` oRPC controller spec; web component test
