## What to build

Let a Purchasing officer submit a complete draft for approval, moving it from Draft to Pending Approval. The status machine permits submission only from Draft, and only when the order is complete (has a supplier, destination store, and at least one valid line).

`Covers:` PO-03 (submit); PO-02 (transition)
`Demo:` buyer01 submits a complete draft; it becomes Pending Approval; an incomplete draft cannot be submitted
`Seams:` oRPC controller spec

## Acceptance criteria

- [ ] Submitting a complete Draft moves it to Pending Approval (oRPC controller spec; fails today — no submit route).
- [ ] Submitting an incomplete order (no lines) is rejected with a Thai actionable error (oRPC controller spec; fails today).
- [ ] Submitting an order that is not in Draft is rejected by the status machine (oRPC controller spec; fails today).
