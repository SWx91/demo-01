## Parent

Part of #1 (Master data and inventory foundation).

## What to build

Add a per-store reorder threshold to products, carried on a store-scoped row so a product can have a different threshold in each store. The threshold cannot be negative. This is the store-scoped stock row that stock balances will later attach to.

`Covers:` MD-01 (reorder threshold per store); MD-02 (non-negative threshold)
`Demo:` Admin sets a reorder threshold of 3 for SKU001, SKU002, SKU003 at B01; a negative threshold is rejected
`Seams:` oRPC controller spec; Zod schema spec

## Acceptance criteria

- [ ] A reorder threshold can be set per product per store and persists on a store-scoped row (oRPC controller spec; fails today — no threshold/store-scoped row).
- [ ] A negative threshold is rejected at the contract boundary (Zod schema spec; fails today).
- [ ] The same product can hold different thresholds in B01 and B02 (oRPC controller spec; fails today).
