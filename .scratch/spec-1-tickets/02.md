## What to build

Give each user an assigned store and derive store scope from the signed-in identity, never from request input. Seed the four workshop users — buyer01 (Purchasing officer), staff_b01 and staff_b02 (Store employees for B01 and B02), manager01 (Manager) — plus an administrator. After signing in, the API knows which store a store employee is bound to.
