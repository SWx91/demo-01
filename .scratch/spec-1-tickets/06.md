## Parent

Part of #1 (Master data and inventory foundation).

## What to build

Let an Administrator create products, with the SKU unique across the whole organization (enforced by a database constraint, not just application code), and give them a management screen to do it. A duplicate SKU is refused.

`Covers:` MD-01 (create); MD-02 (unique SKU)
`Demo:` Admin creates SKU001, SKU002, SKU003; a second product with SKU001 is rejected
`Seams:` oRPC controller spec; web component test

## Acceptance criteria

- [ ] An Administrator creates a product and it persists (oRPC controller spec; fails today — no create route).
- [ ] Creating a second product with an existing SKU is rejected by a database unique constraint, surfaced as a Thai actionable error (oRPC controller spec; fails today).
- [ ] A non-administrator calling create directly is rejected with no data change (oRPC controller spec; fails today).
- [ ] The management screen creates a product and shows loading/success/error states (web component test; fails today).
