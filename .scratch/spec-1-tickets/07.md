## What to build

Let an Administrator edit an existing product's name, category, unit, selling price, and active status, with an edit screen. SKU editing is covered by a later immutability ticket; this ticket edits the mutable fields.

`Covers:` MD-01 (edit)
`Demo:` Admin renames SKU001 and changes its selling price
`Seams:` oRPC controller spec; web component test

## Acceptance criteria

- [ ] An Administrator edits a product's name, category, unit, and selling price, and the change persists (oRPC controller spec; fails today — no edit route).
- [ ] A negative selling price is rejected on edit with a Thai actionable error (oRPC controller spec; fails today).
- [ ] A non-administrator calling edit directly is rejected with no data change (oRPC controller spec; fails today).
- [ ] The edit screen saves changes and shows loading/success/error states (web component test; fails today).
