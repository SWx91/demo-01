## What to build

Let an Administrator deactivate a product while keeping it searchable in historical records, and provide a reusable guard that blocks inactive products from being added to new documents. The purchasing/receiving and sales specs reuse this guard, so it is defined here once.

`Covers:` MD-02 (deactivate, remains searchable); US-07 (inactive blocked from new documents)
`Demo:` deactivate SKU003; it still appears in a historical search but cannot be added to a new document
`Seams:` oRPC controller spec

## Acceptance criteria

- [ ] An Administrator deactivates a product and it remains findable in historical searches (oRPC controller spec; fails today — no active flag handling).
- [ ] Attempting to add an inactive product to a new document is rejected by a shared guard with a Thai actionable error (oRPC controller spec; fails today).
- [ ] A reactivated product can be added to new documents again (oRPC controller spec; fails today).
